Cryptocurrency Market Analytics using Apache Spark

Qasim Tanveer - 24l-2517

This project builds a data pipeline for Bitcoin, Ethereum and Solana market data using Apache Spark. Data comes from the CoinGecko API and includes price, market cap and volume history. It goes through a full load and then daily incremental loads, moving through Bronze, Silver and Gold layers on Databricks. The final output is a Power BI dashboard comparing trends across the three coins.

data folder - full load and incremental load JSON files for each coin
docs folder - project proposal

Tools: Apache Spark, Databricks, Power BI
